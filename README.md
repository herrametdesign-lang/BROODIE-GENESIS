## µOPTHO / OPTHO-RAM

**µOPTHO / OPTHO-RAM** is a research direction investigating whether controllable photonic states can be used as addressable information states within a memory architecture.

The current research focuses on the functional sequence:

**WRITE → HOLD → READ → RESET → ADDRESS**

The project is currently classified as:

**Conceptual / Computational Research — Experimental Validation Pending**

Public-facing technical documentation is maintained separately under the project's Public-Safe documentation scope.
